# 通达信「机构资金雷达」副图指标

基于公开行情 + **Level-2 外盘内盘**的多维度主力资金行为推断指标，**不使用未来函数**，适合 A 股日线短线辅助判断。

> 说明：本指标无法识别真正的「暗盘资金」，通过量价、换手、OBV、VWAP 及 L2 净流比等综合打分，给出吸筹/洗盘/拉升/出货四个阶段的**概率提示**。

## L2 增强说明

### 重要：为何之前副图「几乎一条线」？

旧版使用 `DYNAINFO(22/23)`（外盘/内盘），这是**即时行情函数**：

- 在**日线**上，历史 K 线都会显示**同一天**的内外盘数值
- 导致 `净流比` 与 `净流MA` 几乎相同（如您截图中的 -1.82）
- 底部 ±15 的绿/灰线是**参考阈值线**，不是故障

**修复版**改用日线专用 L2 函数：

| 函数 | 含义 | 是否支持历史 |
|------|------|-------------|
| `ACTINVOL` | 主动买成交量 | **是** |
| `ACTOUTVOL` | 主动卖成交量 | **是** |
| `LARGEINTRDVOL` | 逐笔买入大单量 | **是** |
| `LARGEOUTTRADEVOL` | 逐笔卖出大单量 | **是** |
| `DYNAINFO(22/23)` | 当日内外盘快照 | **否（仅当日）** |

### 如何确认 L2 已生效？

看副图**最右侧**文字标签：

| 标签 | 含义 |
|------|------|
| **L2主动** | 正在使用 ACTINVOL/ACTOUTVOL 真实数据 |
| **L2大单** | 正在使用大单函数（`L2模式:=2`） |
| **估价** | L2 历史未加载，使用 K 线估算（需联网翻页） |

**若显示「估价」**：在联网状态下，从右向左**滑动浏览历史 K 线**，通达信会逐日缓存 L2 资金流向（点播机制），再看是否变为「L2主动」。

### 主公式新增内容

| 项目 | 说明 |
|------|------|
| **L2 权重 12%** | 七维度权重同比缩减至 88%，L2 占 12% |
| **SL2 三项合成** | 买卖比 45% + 净流比 40% + 加速趋势 15% |
| **L2 极端修正** | 大卖+滞涨扣 8 分；大买+持续买加 5 分 |
| **青色 L2强度线** | 净流比映射到 0–100，与白线（评分 MA3）同图对比 |
| **阶段规则增强** | 紫/红/绿阶段可因 L2 净流比提前或强化触发 |
| **L2买 / L2卖** | L2 与阶段共振时的额外标记 |

### 八维度权重（启用 L2 时）

| 维度 | 权重 | 正向信号 |
|------|------|----------|
| 量价背离 | 22% | 量增 20%+ 且涨幅 < 3% |
| 锁仓度 | 18% | 量缩 30%+ 且跌幅 < 1% |
| 控盘度 | 13% | 大阳低换手 |
| OBV 趋势 | 13% | OBV 创 N 日新高 |
| 振幅-换手 | 9% | 高换低振 |
| 尾盘强度 | 9% | 收盘 > 均价 |
| 连续形态 | 4% | 3 日小阳 + 量递增 |
| **L2 净流** | **12%** | 外盘>内盘、净比>5%、加速买入 |

### L2 辅助副图读法

- **净流比柱**：正值=主动买入占优，负值=主动卖出占优
- **大买 / 大卖**：净流比超过 ±15%
- **加速买 / 加速卖**：净流比连续 3 日同向扩大
- **紫色柱**：持续 3 日净流为正；**绿色柱**：持续 3 日为负

## 读图指南

### 主副图协同（L2 版）

| 主图信号 | L2 副图确认 | 可靠性 |
|----------|-------------|--------|
| 红色柱（吸筹） | 净流比 > 0 或「大买」 | 高 |
| 紫色柱（拉升） | 净流比 > 8% 且加速买 | 高 |
| 绿色柱（出货） | 净流比 < -15% 或「大卖」 | 高 |
| 主图高分 | L2 副图「大卖」 | **背离，警惕假突破** |
| 主图「L2买」标记 | L2 副图同时大买 | 共振，可重点关注 |

### 评分区间

| 分数 | 含义 |
|------|------|
| 0–30 | 流出占优 |
| 30–50 | 弱震荡 |
| 50–70 | 试盘/洗盘 |
| 70–85 | 吸筹概率高 |
| 85–100 | 可能拉升（防假突破） |

### 四色阶段

| 颜色 | 阶段 | L2 增强条件 |
|------|------|-------------|
| 绿 | 出货 | L2 大卖/持续卖 + 放量滞涨 |
| 黄 | 洗盘 | L2 非大卖 + 振幅收窄 |
| 红 | 吸筹 | L2 大买/持续买 + 量增价平 |
| 紫 | 拉升 | L2 净比>8% 且 ≥ 均线 + OBV 新高 |
| 灰 | 震荡 | 不满足以上 |

## 使用纪律

1. **L2 仅在个股日线有效**；指数、板块、分钟线未优化
2. **主图 + L2 副图共振** 再考虑行动；单一信号不做唯一买点
3. **主图高分 + L2 大卖** = 典型背离，优先信 L2
4. 震荡市降低 L2权重 至 0.08，减少噪音
5. 70 分是关注线，不是买入线

## L2 故障排除

**Q: 保存时报错 `DYNAINFO`？**  
A: ① 确认已开通 L2 并在个股界面；② 临时设 `启用L2:=0`；③ 部分版本函数编号不同，在函数库查「外盘」「内盘」对应编号替换 22/23。

**Q: L2 强度线/净流比全为 0 或直线？**  
A: 可能在复盘非交易时段，或该品种无 L2 历史；换近期活跃个股测试。

**Q: 主图与 L2 副图数值不一致？**  
A: 主图 L2 已加权并入评分（12%），副图展示原始净流比，二者口径不同，属正常。

**Q: 想加大 L2 影响力？**  
A: 将 `L2权重` 调至 0.15，同时七维度权重自动让位（公式内固定 0.22/0.18/… 合计 0.88）。
