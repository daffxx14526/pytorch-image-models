# 通达信「机构资金雷达」副图指标

基于公开行情数据的多维度主力资金行为推断指标，**不使用未来函数**，适合 A 股日线短线辅助判断。

> 说明：本指标无法识别真正的「暗盘资金」，仅通过量价、换手、OBV、VWAP 等公开字段综合打分，给出吸筹/洗盘/拉升/出货四个阶段的**概率提示**。

## 文件说明

| 文件 | 类型 | 必选 | 说明 |
|------|------|------|------|
| [机构资金雷达.txt](机构资金雷达.txt) | 主副图 | **是** | 0–100 评分 + 四色阶段柱 + 异动标记 |
| [OBV能量潮确认.txt](OBV能量潮确认.txt) | 辅助副图 | 否 | 验证 OBV 趋势与主图信号是否一致 |
| [VWAP偏离.txt](VWAP偏离.txt) | 辅助副图 | 否 | 验证尾盘抢筹/压盘 |
| [L2大单增强.txt](L2大单增强.txt) | 可选模块 | 否 | 需 Level-2 权限，见下文 |

## 安装步骤

### 1. 导入主副图

1. 打开通达信 → **功能** → **公式系统** → **公式管理器**
2. 左侧选择 **技术指标公式** → **其他类型** → **副图**
3. 点击 **新建**，名称填 `机构资金雷达`
4. 打开 [机构资金雷达.txt](机构资金雷达.txt)，**全选复制**粘贴到编辑器
5. 点击 **确定** 保存；若提示语法错误，检查是否完整复制（含注释大括号 `{}`）

### 2. 挂载到 K 线

1. 打开任意 A 股日线 K 线图
2. 输入快捷键 **.504** 或菜单 **分析** → **技术指标** → **其他副图**
3. 选择 **机构资金雷达**
4. 建议副图顺序：**副图1 = 机构资金雷达**；如需辅助，**副图2 = OBV能量潮确认** 或 **VWAP偏离**

### 3. 导入辅助副图（可选）

对 [OBV能量潮确认.txt](OBV能量潮确认.txt) 和 [VWAP偏离.txt](VWAP偏离.txt) 重复上述步骤，分别新建为独立副图公式。

### 4. Level-2 增强（可选）

默认主公式**不依赖 Level-2**，可直接使用。

若已开通 Level-2：

- **方式 A**：单独挂载 [L2大单增强.txt](L2大单增强.txt) 为第三个副图
- **方式 B**：按该文件末尾注释，将 `SL2` 项合并入主公式的 `原始分` 加权式（权重见文件内说明）

> 不同通达信版本的 L2 函数名可能不同（如 `DYNAINFO(22/23)`、`BIGORDER` 等），合并前请对照本地 **函数库** 测试是否报错。

## 默认参数

在公式管理器中选中 `机构资金雷达` → **修改** → 可在源码顶部调整：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| N1 | 5 | 短期均量周期 |
| N2 | 20 | 中期均量/换手周期 |
| N3 | 20 | OBV 新高判定窗口 |
| 涨幅阈值 | 3 | 「价不涨」上限（%） |
| 量增阈值 | 1.2 | 放量倍数 |
| 关注线 | 70 | 评分关注线，触发 ↑关注 |
| 加速线 | 85 | 紫色拉升参考（规则树中关注线为 70） |

### 风格微调建议

| 交易风格 | N1 | N2 | N3 |
|----------|----|----|-----|
| 纯短线（1–5 日） | 5 | 20 | 10–20 |
| 波段（5–20 日） | 10 | 60 | 30 |

## 读图指南

### 评分区间（0–100 柱高）

| 分数 | 含义 |
|------|------|
| 0–30 | 流出占优，偏观望/出货 |
| 30–50 | 弱震荡 |
| 50–70 | 中性偏多，试盘/洗盘 |
| 70–85 | 流入持续，吸筹概率较高 |
| 85–100 | 极强，可能进入拉升（需防假突破） |

### 四色阶段柱

| 颜色 | 阶段 | 典型特征 | 操作建议 |
|------|------|----------|----------|
| 绿 | 出货 | 放量下跌、高位大阴 | 减仓或回避 |
| 黄 | 洗盘/试盘 | 振幅收窄、量能波动 | 不追，等方向 |
| 红 | 吸筹 | 量增价平、评分 45+ | 观察，可分批试探 |
| 紫 | 拉升 | 评分高 + OBV 新高 + 价在 MA20 上 | 持股/跟随，设止损 |
| 灰 | 震荡 | 不满足以上规则 | 观望 |

### 异动标记

- **↑关注**：评分上穿 70
- **加速**：阶段由红（吸筹）转为紫（拉升）
- **减仓**：阶段由紫转绿且放量下跌

### 辅助副图用法

- **OBV能量潮确认**：主图出现红色/紫色柱时，若 OBV 同时创新高，信号更可靠；OBV 新低而主图仍高分，需警惕背离
- **VWAP偏离**：主图吸筹阶段若连续「抢筹」文字/红柱，说明收盘持续高于均价；「压盘」则相反

## 评分模型（七维度）

| 维度 | 权重 | 正向信号 |
|------|------|----------|
| 量价背离 | 25% | 量增 20%+ 且涨幅 < 3% |
| 锁仓度 | 20% | 量缩 30%+ 且跌幅 < 1% |
| 控盘度 | 15% | 涨幅 > 5% 且换手 < 均换 0.8 倍 |
| OBV 趋势 | 15% | OBV 创 N 日新高 |
| 振幅-换手 | 10% | 换手 > 1.5 倍均换且振幅 < 5% |
| 尾盘强度 | 10% | 收盘价 > 当日均价 |
| 连续形态 | 5% | 3 日小阳 + 量温和递增 |

各子项输出 -1~+1，加权后映射为 `(原始分+1)*50`，范围 0–100。

## 使用纪律

1. **副图只做过滤，不做唯一买点**：需结合 MA20/MA60 趋势、股价位置（是否高位）、板块强度
2. **震荡市**：评分 50–70 频繁横跳，降低仓位或只看紫/绿极端色
3. **异常日**：一字板、复牌、重大利好/利空日，指标易失真，应手动忽略
4. **回测验证**：选 20–30 只历史样本，肉眼核对四色与阶段是否大致吻合，再微调参数
5. **70 分是关注线，不是买入线**；**85 分是加速参考，需防拉高出货**

## 常见问题

**Q: 公式保存时报错 `FINANCE` 或 `换手率`？**  
A: 指数/板块 K 线无流通股本，`FINANCE(7)` 可能为 0。请在**个股日线**上使用；或把 `换手率` 行改为贵司版本支持的换手函数（如 `HSL`）。

**Q: 柱状图全是灰色？**  
A: 多数日子处于震荡阶段（PHASE=0）属正常；可尝试缩短 N1/N2 提高灵敏度。

**Q: 与市面「主力资金」指标差异大？**  
A: 本指标 deliberately 采用多维度加权，避免单一「主力进出」柱的过度拟合；以阶段颜色 + 评分为准，勿与单一指标直接对比数值。

**Q: 能否用于分钟线？**  
A: 公式按**日线**设计；分钟线需调整 N1/N2/N3 及 VWAP 计算方式，未做专门优化。
