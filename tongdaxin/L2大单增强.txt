{==================================================================}
{ Level-2 大单增强 - 可选模块                                            }
{ 需要通达信 Level-2 数据权限                                          }
{ 用法: 将下方 L2 加分项合并到「机构资金雷达」的原始分计算中              }
{ 若函数报错, 说明您的版本不支持 L2, 请忽略本文件                       }
{==================================================================}

{--- 以下函数名因通达信版本而异, 请对照本地函数库修改 ---}
{常见 L2 函数参考:}
{DYNAINFO(23)  - 内盘}
{DYNAINFO(22)  - 外盘}
{L2_VOL(0,0)   - 逐笔成交量 (部分版本)}
{BIGORDER(1)   - 大单买入 (部分版本)}

{--- L2 子评分示例 (-1 ~ +1) ---}
{外盘内盘比: 外盘>内盘为资金流入}
外盘:=DYNAINFO(22);
内盘:=DYNAINFO(23);
L2买卖比:=IF(内盘>0,外盘/内盘,1);

SL2:=IF(L2买卖比>1.3,0.8,
    IF(L2买卖比>1.1,0.4,
    IF(L2买卖比<0.7,-0.8,
    IF(L2买卖比<0.9,-0.4,0))));

{--- 合并方式 (在机构资金雷达中替换原始分计算) ---}
{原始分:=S1*0.22+S2*0.18+S3*0.13+S4*0.13+S5*0.09+S6*0.09+S7*0.04+SL2*0.12;}
{权重从 1.0 中划出 12% 给 L2, 其余七维度同比缩减}

{--- 独立 L2 副图 (可选单独挂载) ---}
L2净比:(外盘-内盘)/(外盘+内盘+0.0001)*100,COLORSTICK;
L2均线:MA((外盘-内盘)/(外盘+内盘+0.0001)*100,5),COLORWHITE;
零轴:0,COLOR808080,DOTLINE;

DRAWTEXT((外盘-内盘)/(外盘+内盘)>0.15, L2净比, '大买'), COLORRED;
DRAWTEXT((外盘-内盘)/(外盘+内盘)<-0.15, L2净比, '大卖'), COLOR00AA00;
